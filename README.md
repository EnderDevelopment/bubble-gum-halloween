# BubbleGumHallowen

BubbleGumHallowen is a Roblox script designed for the Solara Executor, offering infinite bubble gum simulator functions and special features for the Halloween event. This script includes various modules to manage, trigger, and handle events related to infinite bubble gum and Halloween themes, providing a comprehensive set of tools for enhancing the gaming experience.

## Install

1. Download the script files from the GitHub repository.
2. Place the files in your Solara Executor scripts directory.
3. Load the script into your Roblox game using the Solara Executor.

## Use

1. Open your Roblox game in the Solara Executor.
2. Load the BubbleGumHallowen script.
3. Use the provided UI to activate infinite bubble gum functions and Halloween event features.
